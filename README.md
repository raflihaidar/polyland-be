# Install Dependencies :

1. Node <= 24
2. postgresql v=16
3. redis v=7.0.15

# Install documentation

1. npm install
2. npx prisma migrate deploy
3. npx prisma db seed role
4. npx prisma db seed module
5. npx prisma db seed role-privilege
6. npx prisma db seed land-office
7. npx prisma db seed province
8. npx prisma db seed regency
9. npx prisma db seed district
10. npx prisma db seed village
11. npx prisma db seed land-certificate
